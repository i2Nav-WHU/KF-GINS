yaml-cpp 常用功能

读取 YAML 文件	        YAML::LoadFile()	从文件加载配置
解析 YAML 字符串	    YAML::Load()	    从字符串解析
获取节点	            config["key"]	    获取指定配置项
类型转换	            .as<int>()	        转换成指定 C++ 类型
判断节点	            .IsDefined()	    判断节点是否存在
创建节点	            YAML::Node	        创建 YAML 数据
保存 YAML	            YAML::Emitter	    序列化 YAML 内容
